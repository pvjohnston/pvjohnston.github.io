How pvjohnston.com is made

pvjohnston.com is a published notebook of private chemistry and computation. This site is Peter’s personal GitHub Pages. It shows the files, the people, and the Mac.

01

The notebook

A note on the site is the end of a short pipeline: question, branch, experiment, draft, checks, pull request, CI, publish. Generated numbers, figures, and tables are supposed to come from committed artifacts. The notebook source is noprofits-org/pvjohnston.com.

Every new note is one of two forms, chosen before drafting.

research understanding falsified traceable

Research

A stated test

A contribution sentence, a hypothesis, and what would falsify it. Written as Abstract through References. The verdict (supported, falsified, inconclusive) is on our hypothesis, not on the source paper.

Understanding

How something works

One explanatory question, in dependency order, with computed demonstrations and a stop where the explanation no longer reaches. No novelty claim.

We are outsiders learning in public. If a published number does not come out on our setup, we write that it did not reproduce for us under these conditions.

lab/johnson-haloacetate/PREREGISTRATION.md## Question

Does carboxylate oxygen charge oscillate with CX3 rotation, with larger amplitude for CCl3COO− than for CF3COO−?

## Hypothesis

On a relaxed CX3 rotation, Hirshfeld and MBIS oxygen charges (and the COO sum) oscillate with the X–Cα–C–O dihedral. Peak-to-peak amplitude is larger for CCl3COO− than for CF3COO−. Acetate is the flat control.

## Falsifier

1. q(O) is flat vs dihedral on both haloacetates, or
2. CF3 amplitude ≥ CCl3 amplitude.

Either outcome is publishable.

What this file is

  1. The question, the guess, and the two ways the guess fails.
  2. Written 2026-08-23, before any geometry is optimized.
  3. A later note on pvjohnston.com will report whichever outcome we get.
lab/johnson-haloacetate/PLAN.mdIf (3) fails in both charge schemes, stop. Do not scan. Write that the charge order did not reproduce for us under these conditions.

Rematch, first

  1. Optimize CH3COO−, CF3COO−, CClF2COO−, and CCl3COO− before starting a rotation.
  2. If both Hirshfeld and MBIS fail to make q(O) more negative on CF3 than on CCl3, we do not scan.
lab/johnson-haloacetate/PLAN.mdDo not inspect q vs φ for an ion until that ion's grid is finished or has failed.

Plotted lines connect adjacent both-converged points only. Unconverged points may be marked; they do not carry a claim.

During the scan

  1. No q vs φ until that ion’s grid is done.
  2. Unconverged points can be marked. They are not used in a claim.
  3. Site numbers come from research/johnson-haloacetate/metrics.json.

04

Authoring

notes/blog-authoring.md is the contract for a note. Research notes use IMRaD. Understanding notes do not get a hypothesis glued on. This page can be easier to read than a note. The notes are still written for someone who may know the subject better than we do. 

notes/blog-authoring.mdcontribution: X, which is not in [source].

Then name its type from the list below. **If you cannot write that sentence,
you do not have a post** — put the topic back on the shelf and pull another.

Before drafting

  1. Write the contribution sentence first.
  2. If you cannot, it is not a Research note that day.

05

The code

Each experiment is a directory under research/, started from research/_TEMPLATE/. The post sets experiment: <slug> and cites [name]{.metric}. The build reads metrics.json and fails if the name is missing. 

scripts/verify-metrics.mjsconst actual = sha256(inputPath);
if (actual !== String(input.sha256).toLowerCase()) {
  errors.push(`${relative(root, metricsPath)}: SHA-256 mismatch for ${input.path}`);
}

verify-metrics.mjs

  1. Each metrics file lists its input paths and SHA-256 hashes.
  2. If a file changed, the check fails.
research/hillel-triplet/generate-metrics.mjsfunction bothConverged(point) {
  if (point.both_converged === true) return true;
  if (point.both_converged === false) return false;
  return point.s0_converged === true && point.t1_converged === true;
}

generate-metrics.mjs

  1. A crossing counts only if both ends converged.
  2. The Hillel note’s claim flag is m4_has_claim_crossing.

Work is on a branch. verify-bib.mjs, verify-metrics.mjs, verify-site.mjs, and a full Hakyll build run in CI. Merge deploys. The checks can show that a named metric matches its artifact. They cannot show that the question was worth asking. The compiler itself — Markdown to HTML, TikZ, citations, print CSS, GitHub Actions — is on the build page.
